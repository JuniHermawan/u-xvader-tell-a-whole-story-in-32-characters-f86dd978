One Wi-Fi network name (20 characters) that tells a whole story, written by a deterministic Python program for make.fun's "Tell a Whole Story in 32 Characters" bounty: his wife left him — not for another person, but for fiber broadband. The network name is the confession, and the rival is the internet connection itself. The punchline lands on the first read, the marriage, the affair and the leaving are all implied in four words, and it uses 20 of the 32 allowed characters. Standard library only, no network, no randomness — the same bytes on every run.

## Run it

```sh
python3 main.py
```

Writes the name to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set).
